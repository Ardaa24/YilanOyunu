🐍 Yılan Oyunu (Snake Game)

Klasik Yılan Oyununun C# ile geliştirilmiş masaüstü versiyonu
Eğitici, basit ve geliştirilmeye açık bir oyun projesi

🎮 Hakkında

Bu proje, klasik Snake (Yılan) oyununu temel alarak geliştirilmiş bir C# Windows Forms uygulamasıdır.
Amaç, oyun mantığını, event yönetimini ve temel grafik çizimlerini öğrenmek ve uygulamaktır.

Proje özellikle:

Programlamaya yeni başlayanlar

Oyun mantığını öğrenmek isteyenler
için iyi bir örnektir.

✨ Özellikler

✔ Klasik yılan oyunu mekaniği
✔ Klavye ile kontrol (yön tuşları)
✔ Yılan uzama sistemi
✔ Yem (food) üretimi
✔ Çarpışma kontrolü (duvar / kendi gövdesi)
✔ Basit ve anlaşılır arayüz

🛠️ Kullanılan Teknolojiler
Teknoloji	Açıklama
C#	Oyun mantığı ve kontrol
Windows Forms	Grafik arayüz
.NET Framework	Uygulama altyapısı
🚀 Kurulum

Repoyu klonla:

git clone https://github.com/Ardaa24/YilanOyunu.git


Visual Studio ile projeyi aç.

.sln dosyasını çalıştır.

Oyunu başlat 🎮

🎯 Oynanış

Yön Tuşları → Yılanı kontrol et

Yemi ye → Yılan uzasın

Duvara veya kendine çarparsan → Oyun biter

💡 Geliştirme Fikirleri

Projeyi bir üst seviyeye taşımak için:

✨ Skor sistemi eklenebilir
✨ En yüksek skor (High Score) kaydı
✨ Zorluk seviyesi (hız artışı)
✨ Ses efektleri
✨ Pause / Resume özelliği
✨ Modern UI (Panel, PictureBox, Timer iyileştirmeleri)

📂 Proje Amacı

Bu proje:

Oyun döngüsü (game loop)

Zamanlayıcı (Timer)

Koordinat & çarpışma mantığı
gibi temel konuları öğretmeyi hedefler.
